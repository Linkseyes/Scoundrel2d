# Scoundrel2dCardGame
The classic single player card game Scoundrel made in Godot

In the game you will be exploring a dungeon full of cards.
You will have to carefully plan which cards to choose in order to survive.
Some will heal you, some will protect you, the rest will try to end your run. 
Can you finish the deck?

# How to play
1. Download the latest release that matches your OS (not currently available on
mac). Unzip the file and start playing.
 
2. Go over to [my itch.io page](https://linkseyes.itch.io/scoundrel-2d) and play directly on the browser.
